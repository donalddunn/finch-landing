# gh-pages — только редирект

Эта ветка существует ради одного: старый адрес `donalddunn.github.io/finch-landing/`
отдаёт редирект на прод `https://finch.neuroproject.tech/`.

Сам лендинг живёт в `main` — оттуда пайплайн НейроПроекта выкладывает статику
в Yandex Object Storage. Ветку `main` держим чистой, поэтому редирект вынесен сюда.

Если GitHub Pages переключат обратно на `main`, редирект перестанет работать.
